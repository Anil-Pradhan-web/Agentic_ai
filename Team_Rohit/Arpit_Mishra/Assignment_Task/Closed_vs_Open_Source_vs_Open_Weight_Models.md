# Difference Between Closed, Open Source, and Open Weight Models

## Introduction

AI models are distributed in different ways depending on access to their code, architecture, and trained weights.

---

## Comparison

| Feature | Closed Model | Open Source Model | Open Weight Model |
|----------|-------------|------------------|------------------|
| Source Code | No | Yes | Sometimes |
| Model Weights | No | Yes | Yes |
| Training Data | No | Often | Usually No |
| Modification | No | Yes | Limited |
| Commercial Usage | Restricted | Usually Allowed | Depends on License |

---

## Closed Models

Examples:
- GPT-5.5
- Claude
- Gemini

Advantages

- Highest performance
- Professionally maintained
- Better safety

Disadvantages

- Paid APIs
- No customization
- Limited transparency

---

## Open Source Models

Examples

- OLMo
- BLOOM

Advantages

- Fully transparent
- Highly customizable
- Community driven

Disadvantages

- Requires significant computing resources
- Maintenance responsibility lies with the user

---

## Open Weight Models

Examples

- Llama
- Mistral
- Gemma

Advantages

- Run locally
- Fine-tune possible
- Lower cost

Disadvantages

- Source code or training data may not be fully available
- License restrictions may apply

---

## Conclusion

Closed models provide convenience and high performance, open-source models maximize transparency and flexibility, and open-weight models offer a practical balance by releasing trained weights while retaining some proprietary components.
