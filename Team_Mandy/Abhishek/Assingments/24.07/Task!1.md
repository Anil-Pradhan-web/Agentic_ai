What is the difference between Close Source Model and Open Source and Open Weight Model

Closed-source models are proprietary to the company that have developed it. 
Users can access them through APIs or applications, but cannot see or modify how they are built.

Some feature of Closed-Source models are:
->High Performane
->Regular Supports
->vendor lock-in

Some examples:
->GPT 5.5(OpenAI)
->Claude(Anthropic)
->Gemini(Google)


Open-source models are generally the models those provides the complete project.

Some features are:
->Complete Transparency
->Good for reasearch 
->Easy to modify

Some examples:
->GPT-NeoX
->BLOOM


Open-Weight Models are those models whose only trained weights are released.

Some features:
->easy to deploy locally
->supports fine tuning
->lower cost

Some examples:
->Llama 3
->Gemma
->Mistral
